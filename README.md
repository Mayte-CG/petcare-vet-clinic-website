# PetCare Veterinary Clinic Website

A responsive veterinary clinic website built with HTML, CSS, and JavaScript.

The project recreates a provided design reference as a functional multi-page website. It includes responsive layouts, interactive navigation, scroll-triggered animations, and a separate contact page.

## Live Demo

[View the live website](https://mayte-cg.github.io/petcare-vet-clinic-website/)

## Project Overview

PetCare is a fictional veterinary clinic website designed to present the clinic's services, pricing plans, key benefits, testimonials, and contact information.

The main goal of the project was to translate a visual reference into a complete website while maintaining a consistent design across different screen sizes.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Mobile navigation menu
- Full-screen hero section
- Services section with circular images
- Animated statistics triggered on scroll
- Responsive pricing cards
- Pet owner benefits section
- Testimonial section
- Contact page with a styled form
- Accessible hover, active, and focus states
- Smooth visual transitions and decorative background elements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- CSS animations
- Git and GitHub
- GitHub Pages

## Main Sections

The homepage includes:

1. Navigation and hero section
2. Services
3. About the clinic and animated statistics
4. Pricing plans
5. Reasons why pet owners trust the clinic
6. Customer testimonial
7. Footer and contact information

The project also includes a separate contact page with a responsive form.

## Responsive Design

The layout adapts to different screen sizes using CSS media queries. Navigation, content grids, pricing cards, typography, and footer elements are reorganized for tablets and mobile devices.

## Running the Project Locally

No installation or build process is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Mayte-CG/petcare-vet-clinic-website.git
   ```

2. Open the project folder.

3. Open `index.html` in a web browser.

You can also use an extension such as Live Server in Visual Studio Code.

## Design Reference

The website was developed from a provided design reference. The reference image is stored in the `assets/design` directory.

The implementation focuses on reproducing the visual hierarchy, color palette, section structure, typography, and overall appearance of the original design while adding responsive behavior and interactive elements.

## Deployment

The website is deployed with GitHub Pages from the `master` branch and the repository root directory.
